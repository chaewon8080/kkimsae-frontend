# 낌새 프론트엔드


## 실행

```bash
npm install
cp .env.example .env
npm run dev
```
## 생성형 AI 활용 내역

React 프론트엔드 개발 과정에서 화면 구성, 컴포넌트 코드 작성,
백엔드 API 연동 및 오류 해결에 ChatGPT를 활용했습니다.
